# ai-sandbox-dashboard

Наблюдательная страница конвейера онбординга протоколов DefiDash. **Только чтение**: ни одного
действия отсюда сделать нельзя, решения принимаются командой `sandboxctl` или кнопкой в Telegram.

## Как это работает

```
бокс ai-sandbox                       этот репозиторий                 GitHub Pages
sandboxctl export ──(раз в 2 мин)──>  ветка data: snapshot.json  <──fetch──  ветка main: страница
      (deploy key с правом записи)     история из одного коммита            (index.html/app.js)
```

Страница забирает снимок не из своей ветки, а с `raw.githubusercontent.com`. Причина: у Pages
мягкий лимит **10 сборок в час**, а снимок обновляется раз в две минуты — если держать его в
собираемой ветке, лимит кончится за час. Ветка `data` не собирается, поэтому пересборок нет
вовсе. Плата — кэш `raw` до ~5 минут, поэтому в заголовке всегда виден возраст снимка.

История ветки `data` намеренно состоит из одного коммита (`git commit --amend` +
`push --force-with-lease`): снимок состояния не нуждается в истории, а 720 коммитов в сутки
превратили бы репозиторий в свалку.

## Репозиторий публичный — что из этого следует

Снимок собирается **по белому списку полей** на стороне бокса
(`detracker/ai-sandbox:orchestrator/export.py`), и перед записью проверяется: если в нём
окажется эндпоинт RPC, IP, путь на хосте, домашний каталог, префикс токена или ключ — файл не
пишется вообще. Причины отказов `doctor` наружу не уходят, только имена проверок и `ok`/`fail`.

Имена протоколов в снимке видны по умолчанию; это продуктовый сигнал о том, что подключается
следующим, и выключается настройкой `public_names: false` на боксе.

## Локальный просмотр

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

Страница без сборщика и без зависимостей: `index.html`, `app.js`, `style.css`.
